Real-world Setup¶

We mount a Jetson Orin AGX 64GB on the Unitree Go2 robot.
For detailed hardware information and CAD files, please refer to REASAN.

NVIDIA Jetson AGX Orin Setup¶

Flash the System¶

  • Hardware setup follow the guidance
    • First finish L4T BSP flash step
  • SDK Manager Step1
    • choose Jetson AGX Orin [64GB developer kit version], JetPack 6.2.1
    • Do NOT select Host Machine
  • SDK Manager Step2
    • Only select the first Jetson Linux
    • Do NOT select Jetson Runtime Components Click Contine
      Click Create
      Then click Continue and input your sudo password
  • SDK Manager Step3 IMPORTANT!
    Choose RUNTIME and NVME (if with ssd inside)

    Click Flash
    After a while, it goes back to this page again

    Usually this step takes about 5-8 minutes
  • SDK Manager Step4
    Done!

Install SDK Components¶

First make sure you finish first flashing step and install ubuntu already, finish ubuntu initial setups first. Do NOT run sudo apt update or upgrade at this step, it may cause version mismatch errors later. Follow this guide.

  • SDK Manager Step 1
    No need to make AGX Orin be in Force Recovery Mode, just wait for some time then it can be detected.
  • SDK Manager Step 2
    Select SDK components we want:
    When you click SDK components, some Runtime components required for SDK components will be automatically selected. Click Continue and input your sudo password.
  • SDK Manager Step 3
    And set configuration like this. Input username and password you set for ubuntu in jetson agx orin: Click install: Notes:
    Sometimes it encounters device image version matching requirement, follow this guide. This may be caused by sudo apt update and upgrade at initial setups of ubuntu, you can reflash Jetson AGX Orin to solve this mismatch.
  • SDK Manager Step 4
